# Hanzi OCR

This repository hosts the code for my Hanzi OCR project, it is divided into three distinct planned phases (as of writing this)

1. OCR for individual characters, the compatible character list is obtained from https://github.com/krmanik/HSK-3.0
2. An OCR for lines written in Chinese (these usually contain Hanzi, punctuation, writing in latin script, and arabic numerals). 
3. An OCR for multiple lines of Chinese writing
